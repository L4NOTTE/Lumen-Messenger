# Lumen Messenger

Настольный мессенджер для Windows на Rust. В Lumen есть локальные группы, защищённые диалоги через интернет, демонстрация экрана и встроенный прокси VLESS / REALITY.

## Установка

1. Откройте [GitHub Releases](https://github.com/L4NOTTE/Lumen-Messenger/releases) и скачайте `Lumen-Messenger-<версия>-x64.msi` из опубликованного выпуска.
2. Запустите установщик и откройте **Lumen Messenger** из меню «Пуск». Для работы интерфейса нужен Microsoft Edge WebView2 Runtime.
3. Для обновления запустите новый MSI поверх установленной версии. Windows Installer заменит приложение, а чаты, профиль и настройки сохранятся в `%LOCALAPPDATA%\Lumen Messenger`.

Сборки с настроенным каналом проверяют подписанные обновления в разделе **Настройки → О приложении**. При переходе со сборки без канала первый MSI нужно установить вручную.

## Возможности

- **Локальные группы.** Создавайте группы для участников в одной локальной сети и приглашайте их одноразовым кодом. Ответ на приглашение передаётся автоматически.
- **Защищённые диалоги.** Два участника общаются через сервер Lumen по WSS. Имя собеседника видно в заголовке, а имя отправителя — над сообщением. Noise Protocol шифрует имена и сообщения на устройствах. Сервер пересылает зашифрованные пакеты без сохранения истории.
- **Демонстрация экрана.** Доступна в локальных группах и защищённых диалогах. Можно выбрать экран или окно, разрешение 720p, 1080p либо 1440p и частоту 30 либо 60 FPS. Видео передаётся без звука. В интернет-диалоге зритель принимает приглашение к просмотру.
- **Локальная история.** Поиск, ответы с цитатой, закрепление, «Избранное» и действия с вложениями по правому клику. Лимит составляет 1 ГиБ на файл.
- **Прокси Lumen.** Импорт VLESS-ключей и подписок, выбор сервера и подключение через Xray. Прокси используется приложением.
- **Новости и оформление.** Полные описания и файлы релизов из GitHub Releases, светлая и тёмная темы, акцентный цвет, масштаб и фон переписки.

## Как подключиться

**Локальная группа.** Откройте группу, нажмите **Локальная связь → Создать код** и передайте код участнику. Он вставляет код через **Войти в локальную группу**. Код действует пять минут и рассчитан на одного участника.

**Защищённый чат через интернет.** В настройках профиля укажите имя, которое увидит собеседник. Откройте **Защищённый чат**, введите адрес сервера Lumen, например `wss://ваш-домен/chat`, и создайте комнату. Передайте собеседнику полное приглашение или QR-код. Короткий код можно использовать, если у обоих выбран один и тот же сервер. Приглашение содержит ключ комнаты, поэтому передавайте его только собеседнику. Если временный туннель сменил адрес, создайте новую комнату с новым адресом и отправьте новое приглашение.

**Показ через интернет.** В подключённом защищённом чате нажмите **Показать экран**. Собеседник нажимает **Смотреть показ**. Если сеть блокирует прямое соединение, понадобится TURN. Параметры подключения описаны в [документации сервера](server/README.md).

## Сборка из исходников

Для клиента нужны Windows x64, Rust с целью `x86_64-pc-windows-msvc`, инструменты сборки MSVC, Windows SDK и Microsoft Edge WebView2 Runtime.

```powershell
cargo build --locked --release
```

Для сборки MSI нужен совместимый `xray.exe`. Сценарий проверяет его хеш и упаковывает его вместе с приложением.

```powershell
& .\installer\build.ps1 -Xray 'C:\путь\к\xray.exe'
```

Сервер можно [запустить на Python под Windows](server/README.md#запуск-на-python-под-windows) или собрать на Rust.

```sh
cargo build --release --locked --manifest-path server/Cargo.toml
```
