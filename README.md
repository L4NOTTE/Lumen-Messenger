# Lumen Messenger

Настольный мессенджер для Windows с локальными группами, защищёнными диалогами через интернет, демонстрацией экрана и прокси VLESS / REALITY.

## Установка

1. Откройте [GitHub Releases](https://github.com/L4NOTTE/Lumen-Messenger/releases) и скачайте файл `Lumen-Messenger-<версия>-x64.msi` из опубликованного релиза.
2. Запустите установщик и откройте **Lumen Messenger** из меню «Пуск». Приложению нужен Microsoft Edge WebView2 Runtime.
3. Обновления доступны в разделе **Настройки → О приложении**. Также можно запустить новый MSI поверх установленной версии. Чаты, профиль и настройки сохраняются.

## Возможности

- **Локальные группы** для участников одной сети с подключением по одноразовому коду.
- **Защищённые диалоги** для двух участников через сервер Lumen. Имена и сообщения шифруются на устройствах с помощью Noise Protocol. Сервер пересылает зашифрованные пакеты без сохранения истории.
- **Демонстрация экрана** в локальных группах и защищённых диалогах. Можно показать окно или весь экран без звука в 720p, 1080p или 1440p при 30 или 60 FPS.
- **Локальная переписка** с поиском, ответами, закреплением, избранным и вложениями до 1 ГиБ на файл.
- **Оформление и профиль** с фото, светлой и тёмной темами, акцентным цветом RGB, масштабом и фоном переписки.
- **Новости и обновления** из GitHub Releases. Приложение проверяет подпись манифеста и хеш пакета перед обновлением.

## Как начать переписку

**В локальной сети.** Откройте группу, нажмите **Локальная связь → Создать код** и передайте код собеседнику. Он вставляет код через **Войти в локальную группу**.

**Через интернет.** Укажите имя в настройках профиля. Откройте **Защищённый чат**, введите адрес сервера вида `wss://ваш-домен/chat` и создайте комнату. Отправьте собеседнику полное приглашение или QR-код и оставьте комнату открытой. Короткий код подходит, если у обоих выбран один сервер. Передавайте приглашение только собеседнику, поскольку оно содержит ключ комнаты.

## Как показать экран

В защищённом чате нажмите **Показать экран** и выберите окно или экран. Начиная с **v0.7.5**, у ведущего сразу появляется локальное превью. Собеседник нажимает **Смотреть показ**, чтобы увидеть трансляцию. Если сеть блокирует прямое видеосоединение, настройте TURN. Параметры указаны в [документации сервера](server/README.md).

## Сборка

Для клиента нужны Windows x64, Rust с целью `x86_64-pc-windows-msvc`, инструменты сборки MSVC и Windows SDK.

```powershell
cargo build --locked --release --target x86_64-pc-windows-msvc
```

Для сборки установщика нужен `xray.exe` с хешем, указанным в `src/vpn.rs`.

```powershell
& .\installer\build.ps1 -Xray 'C:\путь\к\xray.exe'
```
